# Models

The weights are not kept in git: download them from the
[GitHub release](https://github.com/anatoliiii/focalprint/releases/tag/v0.1.0)
into `models/public/` and check them:

```sh
cd models/public && sha256sum -c ../SHA256SUMS
```

| File | What |
|---|---|
| `public/fpnet-distill-kd.onnx` | FpNet for `focalprintd` / `focalprint neural`: input `frame` f32[1,1,80,64], outputs `desc` f32[1,128,40,32], `rel` f32[1,1,40,32] |
| `public/distill-kd.pt` | The same weights as a PyTorch checkpoint (`research/fpnet.py`: `load()`), for fine-tuning |
| `private/` | Models trained on real people's frames. Never committed (see `.gitignore`) |

## `distill-kd`: provenance

- Architecture: FpNet, `dim` 128, `width` 3, `context` 3; 5.0 M parameters.
- Trained by `research/distill.py` for 15 000 iterations on public
  fingerprint datasets (2 257 impressions) and 4 000 synthetic ones. **No
  private frames** went into this model.
- Knowledge distillation: a teacher trained on private FT9368 frames supplied
  target descriptors, computed on the public images only. The student never
  saw a private frame, but its behaviour imitates a model that did.
- Exported with `research/export_onnx.py`.

## Quality and threshold

Measured on the FT9368 (FTE4800, SPI). The FT9201 (USB) has the same
64×80 frame but different optics and contrast; expect the score scale to
shift and **calibrate the threshold on your sensor** (below).

Offline, private test set (`research/eval2.py`); FRR = genuine touches
rejected, FAR = impostor touches accepted:

| Threshold | Known fingers, new touches | Fingers never seen in training |
|---|---|---|
| 0.287 (1 % FAR on validation) | FRR 36.9 %, FAR 0.71 % | FRR 35.3 %, FAR 1.80 % |
| 0.410 (zero FAR on validation) | FRR 44.7 %, FAR 0 % | FRR 61.8 %, FAR 0 % |

Live, `focalprint neural --fingers 2 --threshold 0.41`, 20 touches: 15
accepted, 5 rejected, no finger ever taken for the other. Rejected touches
scored like impostors (0.19–0.30), not just under the threshold: they showed
skin the enrolment had not covered. The daemon's adaptive template (see the
main README) closes most of that gap over the first days of use.

FT9201 (USB, TECNO MegaBook K16S), live, `--fingers 2 --threshold 0.41`,
20 touches including other, non-enrolled fingers: no false accept; genuine
matches scored 0.56–0.65, other fingers at most 0.37. Use `--threshold 0.45`
on this sensor.

Recommended start: `--threshold 0.41` (FT9368) or `0.45` (FT9201). To calibrate, run
`sudo focalprint --backend usb neural --model models/public/fpnet-distill-kd.onnx --fingers 2 --threshold 0.41`
and compare the scores of genuine touches with the other finger's score
(printed in brackets). Pick a threshold clearly above the highest
other-finger score you see.
